# PRODIGY_DS_01

## Data Science Internship – Task 01

### Project Title
Population Distribution Visualization

### Objective
To create a Bar Chart and Histogram to visualize population distribution using the Prodigy InfoTech provided dataset.

### Dataset
Population, Total – World Bank Dataset

Source: https://data.worldbank.org/indicator/SP.POP.TOTL

### Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab

### Project Steps
1. Imported the dataset.
2. Explored and cleaned population data.
3. Selected the year 2024.
4. Identified the top 10 most populated countries.
5. Created a Bar Chart.
6. Created a Histogram.

### Visualizations
- Top 10 Most Populated Countries (2024)
- Population Distribution Across Countries (2024)

### Conclusion
This project demonstrates the use of Python for data analysis and visualization using real-world population data.
